# Начало использования

## Установка зависимостей

```bash
uv sync --group visual
```

## Запуск

```bash
uv run src/llmops_toys/visualize/visualize.py
```

В качестве тестового текста взята краткая аннотация к книге Chip Houyen "AI Engineering" (приведёны примеры на двух языках для разных моделей).

Построение тепловой карты реализовано для последнего слоя внимания, используется среднее значение по всем головам -- так мы получаем возможность выделить итоговые, наиболее важные связи между токенами, свойственные для выбранного для анализа текста.

Для управления параметрами запуска используется конфигурационный файл **src/llmops_toys/config/default.yaml** или можно использовать флаги командной строки (см. пример использования [Getting Started Hydra](https://hydra.cc/docs/intro/))

Результаты выполнения приложены в директории **docs/visualize_attention/{model_name: bert,gpt,ruBert}/{language: english,russian}/**. Для запуска визуализации с другими моделями достаточно создать yaml файл в директории **src/llmops_toys/config/model/** и указать его в default-конфигурации.

Для просмотра результатов визуализации необходимо выполнить

```bash
git lfs pull
```

(а также установить [git-lfs](https://github.com/git-lfs/git-lfs), если по какой-то причине его вдруг нет в вашей системе)

Несколько скриншотов вывода model_view модели **google-bert/bert-base-uncased** для анализа заданного текста на английском языке для нескольких первых слоёв приведены в директории с выводами [bert/english/](bert/english/).

## Анализ

Визуализация нагладно демонстрирует, что модели семейства BERT распределяют внимание на токены как до, так и после текущего токена, тогда как GPT-2 использует максированное внимание только к предыдущим токенам. На тепловых картах это заметно, так как внимания у causal-ной модели нижняя треугольная, на визуализации связи также указаны только к предыдущим токенам, тогда как у энкодерных моделей все связи равномерно распределены по пространству токенов как на тепловой карте, так и послойных визуализациях.

## Сравнение работы моделей на текстах на разных языках

Помимо особенностей внимания, различающихся для энкодерных и декодерных моделей, имеет смысл обратить внимание на различие в работе с текстом на разных языках. На примере всё тех же моделей имеет смысл рассмотреть, как исходные датасеты для обучения влияют на восприятие модели. Так, мы проанализируем, как модели, обученные на текстах на разных языках (английском и русском), понимают язык, на котором "велось обучение" (хотя это не вполне корректная формулировка в данном случае) и понимают ли язык незнакомый.


### GPT и BERT на незнакомом русскоязычном тексте

Обе модели на этапе токенизации превратили текст в полный фарш, разделив все слова побуквенно и не уловив ни единого смысла (и на визуализациях, и на тепловых картах видно, что токены не связаны между собой). В том время как с английским языком обе справились.

### ruBERT

В то же время русскоязычный ruBert справился с полноразмерным русским текстом, адекватно токенезировав текст и разделив его на смысловые важные блоки, а также разобрав слова по составу (например, слово "базовые" распалось на 2 токена: "баз" и "##овые", "снизив" - на 2 токена "сниз" и "##ив").

Он также отлично справился и с английским текстом, что было ожидаемо, учитывая происхождение этой модели (то, что он получен из BERT добавлением знаний о русском языке, то есть прежние знания английского языке сохранились в весах модели даже после доубучения).

## Модели, использованные для анализа

- BERT: [google-bert/bert-base-uncased](https://huggingface.co/google-bert/bert-base-uncased)
- GPT2: [openai-community/gpt2]((https://huggingface.co/zhuojing-huang/openai-community/gpt2)
- ruBERT: [DeepPavlov/rubert-base-cased](https://huggingface.co/DeepPavlov/rubert-base-cased)


*Примечание.* Для BERT и GPT2 результаты визуализаций с помощью библиотеки bertviz не приложены, т.к. html-файлики гигантические и ёмкости lfs-storage под них не хватает. Учитывая недоумение, которое кириллический текст вызывает у обеих англоговорящих моделей, данные графики являются неинформативными, в то время как тепловые карты лишь подтверждают все высказанные ранее выводы.
