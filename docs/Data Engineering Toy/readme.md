
# Анализ тональности и извлечение сущностей в русскоязычных текстах

## Описание проекта

Этот проект реализует сравнительный анализ двух подходов к анализу русскоязычных текстов:
1. **HuggingFace модели** - использует предобученные модели для анализа тональности и извлечения именованных сущностей
2. **LLM (Large Language Model)** - использует промпты для анализа через OpenAI API

## Структура проекта

```
.
├── data_engineering/
│   ├── accuracy.py          # Тестирование точности моделей
│   ├── serialize.py         # Работа с данными (сохранение/загрузка)
│   ├── data_engineering.py  # Очистка и подготовка данных
│   ├── prompting.py         # Работа с промптами для LLM
│   ├── main.py              # Основной скрипт запуска
│   └── compare.py           # Сравнение результатов моделей

└── README.md                # Этот файл
```

## Зависимости

Для установки необходимых зависимостей выполните:

```bash
uv sync
```

Требуемые библиотеки перечислены в pyproject.toml-файле.

## Настройка OpenAI API

Для работы с LLM необходимо установить переменные окружения:

```bash
export OPENAI_API_KEY="ваш_ключ_от_OpenAI"
export OPENAI_API_BASE="ваш_OperAI_endpoint_url"
```

## Использование

### 1. Подготовка данных

Файл `data_engineering/main.py` содержит функцию `load_raw_data()` для загрузки сырых данных. В текущей реализации используются тестовые отзывы.

### 2. Запуск анализа

```bash
uv run data_engineering/main.py
```

### 3. Результаты

После запуска будут выведены:
- Результаты анализа с помощью HuggingFace моделей
- Результаты анализа с помощью локально развёрнутой LLM
- Сравнительные метрики
- Визуализации результатов
- Отчет о сравнении

## Основные компоненты

### data_engineering/accuracy.py
- Тестирование точности моделей на заранее подготовленных тестовых примерах
- Расчет точности для HuggingFace и OpenAI моделей

### data_engineering/serialize.py
- Сохранение данных в форматах JSONL и CSV
- Загрузка данных из файлов
- Валидация форматов данных

### data_engineering/data_engineering.py
- Очистка и нормализация русскоязычных текстов
- Искусственное добавление разметки для обучения

### data_engineering/prompting.py
- Создание промптов для LLM
- Работа с OpenAI API
- Анализ текстов с использованием промптов

### data_engineering/compare.py
- Сравнение результатов работы HuggingFace и LLM моделей
- Расчет метрик точности
- Визуализация результатов
- Генерация отчетов

## Промпты для LLM

Созданы два типа промптов:
1. **NER (Named Entity Recognition)** - извлечение именованных сущностей
2. **Sentiment Analysis** - анализ тональности текста

## Тестирование

Проект включает тестовые примеры с различными типами текстов:
- Сарказм и ирония
- Смешанные эмоции
- Сложные структуры предложений
- Неформальная речь и сленг
- Простые случаи для контроля

## Визуализация

Создаются графики:
- Сравнение времени обработки
- Сравнение количества извлеченных сущностей
- Сравнение точности по метрикам
- Точность моделей по отдельности

## Отчет

Генерируется подробный отчет с выводами по сравнению моделей

## Тестовые данные

В файле `data_engineering/accuracy.py` содержится набор тестовых примеров с правильными ответами:
- Сарказм и ирония - должны быть NEGATIVE
- Смешанные эмоции - должны быть NEUTRAL или зависят от преобладающего тона
- Сложные структуры - требуют понимания контекста
- Неформальная речь и сленг
- Простые случаи для контроля
