

# RAG и векторные БД

В рамках подпроекта `src/rag` реализовано сравнение производительности для различных подходов поиска в базе данных Chroma. Он также позволяет сравнивать эффективность разных стратегий поиска с использованием различных метрик схожести (конусное сходство, эвклидово расстояния и скалярное произведение). Для каждого из варианта метрик реализованы следующие виды поиска:

- Базовый поиск без фильтрации
- Поиск с фильтрацией по тегам
- Поиск с ограниченным количеством результатов
- Поиск с фильтрацией по дистанции
- Комбинированная оптимизация

Проект автоматически создает три отдельных окружения с разными метриками схожести для комплексного сравнения, а в качестве результата выдает подробный отчет с рекомендациями по выбору наиболее эффективного подхода в зависимости от требований к скорости. Система анализирует время выполнения, количество результатов и производительность для каждой метрики, позволяя определить оптимальную стратегию поиска для конкретной задачи. Оценка точности в данном подходе не производится.

# Пример использование

```bash
uv run src/llmops_toys/rag/main.py
```
