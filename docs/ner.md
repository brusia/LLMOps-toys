# Извлечение сущностей из юридических документов

Подпроект /src/llmops_toys/ner реализует решение для извлечения сущностей из юридических контрактов с использованием локальных моделей.

## Возможности

- Загрузка и подготовка данных из датасета CUAD
- Извлечение сущностей: PERSON, ORG, MONEY, DATE, CONTRACT_TYPE, OBLIGATION, JURISDICTION
- Поддержка batch processing для повышения эффективности
- Анализ производительности моделей
- Сравнение различных конфигураций моделей

## Установка

```bash
uv sync --group ner
```

## Использование

### Запуск с реальными данными:
```bash
uv run src/llmops_toys/ner/main.py --dataset-size 1000 --analyze-performance
```

### Запуск с различными размерами пакетов:
```bash
uv run src/llmops_toys/ner/main.py --batch-size 8 --analyze-performance
```

## Архитектура проекта

- `src/llmops_toys/ner/data_loader.py` - Загрузка и подготовка данных
- `src/llmops_toys/ner/prompts.py` - Промпты для извлечения сущностей
- `src/llmops_toys/ner/model_runner.py` - Запуск моделей и извлечение сущностей
- `src/llmops_toys/ner/batch_processor.py` - Обработка пакетов для повышения эффективности
- `src/llmops_toys/ner/performance_analyzer.py` - Анализ производительности
- `src/llmops_toys/ner/main.py` - Главный скрипт запуска

## Результаты

После выполнения проекта создаются следующие файлы:
- `data/ner/<model-name>/cuad_subset.json` - Подвыборка датасета CUAD
- `data//ner/<model-name>/entity_extraction_results.json` - Результаты извлечения сущностей

В качестве примера использованы следующие модели

- Qwen/Qwen2-0.5B
- TinyLlama/TinyLlama-1.1B-intermediate-step-1431k-3T
- deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B

## Рекомендации
Для задачи извлечения сущностей из юридических документов рекомендуется использовать **Qwen/Qwen2-0.5B** благодаря высокой пропускной способности и эффективности.

## Примечание

Ввиду того, что размеры моделей не вполне сопоставимы, представляется не очень "честным" сравнивать их производительность при исполнении на cpu. Тем не менее в учебных целях данный проект предосталяет возможность произвести такое сравнение. Несмотря на то, что выводы отчасти искусственны, сам процес размышлений при этом является полностью корректным.
